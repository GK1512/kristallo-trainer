Политика конфиденциальности

Приложение «Кристаллы» — тренажёр по кристаллографии (Android и веб-версия)

Коротко

Приложение не требует регистрации, не показывает рекламу, не использует аналитику и трекеры и не собирает персональные данные. Всё, что вы делаете в тренажёре, хранится только на вашем устройстве.

Что хранится на устройстве

  • результаты контрольных и статистика ошибок (раздел «Прогресс»);
  • настройки: язык, тема оформления, последняя открытая вкладка.

Эти данные никуда не передаются. Их можно удалить кнопкой «Сбросить» в разделе «Прогресс», очисткой данных приложения или данных сайта в браузере.

Форма обратной связи

Если вы сами отправляете сообщение об ошибке, автору передаются:

  • текст сообщения и выбранный тип (ошибка в ответе, в теории, сбой, идея);
  • контакт для ответа — только если вы его указали;
  • если отмечено «Приложить, где я нахожусь»: раздел приложения (например, номер задачи или тема теории), тип устройства, размер экрана, язык и номер сборки.

Сообщение пересылается на почту автора через сервис Web3Forms. Оно используется только для исправления ошибок и ответа вам и не передаётся третьим лицам. Чтобы удалить отправленное сообщение, напишите об этом через ту же форму.

Разрешения Android

Приложение запрашивает только доступ в интернет — он нужен для отправки сообщений обратной связи. Доступа к камере, микрофону, контактам, файлам, местоположению, SMS и специальным возможностям у приложения нет.

Веб-версия

Сайт размещён на GitHub Pages. Как и любой хостинг, GitHub может вести технические журналы запросов (например, IP-адрес) — см. политику GitHub. Для работы без интернета сайт сохраняет свои файлы в кэше браузера.

Дети

Приложение предназначено для студентов и не собирает данные пользователей любого возраста.

Изменения и связь

При изменении политики новая версия публикуется на этой странице. Вопросы можно задать через форму обратной связи в приложении (кнопка с облачком в правом верхнем углу).

Privacy policy (English summary)

“Crystals” (a crystallography trainer) requires no sign-up and has no ads, analytics or trackers. Progress and settings are stored only on your device. If you choose to send feedback, the message text, the optional contact you enter and, if ticked, the app section, device type, screen size, language and build number are forwarded to the author by email via Web3Forms; they are used only to fix errors and reply. The Android app requests only the Internet permission, used for feedback. The web version is hosted on GitHub Pages. Questions: use the in-app feedback form.
