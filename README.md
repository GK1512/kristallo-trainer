# Кристаллы — тренажёр по кристаллографии

Приложение для подготовки к контрольной по геометрической кристаллографии (по учебному пособию
Е. Н. Завьялова «Кристаллология» и практикуму МГРИ). Работает без интернета.

## Скачать

- **Android:** [kristallo-trainer.apk](../../releases/latest/download/kristallo-trainer.apk) — последняя версия.
  Откройте файл на телефоне и разрешите установку из этого источника. Новые версии ставятся поверх старой.
- **iPhone и компьютер:** https://gk1512.github.io/kristallo-trainer/
  На iPhone откройте ссылку в Safari → «Поделиться» → «На экран „Домой“».
